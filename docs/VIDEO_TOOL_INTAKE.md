# VIDEO / AUDIO TOOL INTAKE

動画・音声編集、生成、変換ツールを作る場合の追加質問です。AIは一度に全部を聞かず、PROJECT_BRIEFの主要な利用場面に関係するものから1〜3問ずつ聞いてください。

## 1. 何を編集するか

- 入力は動画、静止画、音声、字幕、台本、画面操作のどれか
- 対応したい拡張子・コーデックは何か
- 縦横比、解像度、フレームレート、色空間の想定は何か
- 1本あたりの長さ・容量・素材数はどれくらいか
- 可変フレームレートや透過素材を扱うか

## 2. 編集の考え方

- タイムライン型、台本型、テンプレート型、自動生成型のどれか
- 切る、並べる、重ねる、拡大、移動、色調整、速度変更のどこまで必要か
- やり直し、履歴、比較、下書き保存が必要か
- 一括変更と素材ごとの個別変更をどう分けるか
- 過去作品を同じ結果で再生成する必要があるか

## 3. 音声

- ナレーション、会話、BGM、効果音、環境音のどれを扱うか
- 音量、パン、フェード、ダッキング、ラウドネスの条件は何か
- 音声合成を使うか。ローカルかクラウドか
- キャラクター・プリセット単位の設定と、1箇所だけの上書きが必要か
- 無音、音割れ、欠落をどう検出するか

## 4. 字幕・文字

- 自動字幕、手入力、台本から生成のどれか
- フォント、縁取り、位置、アニメーション、複数言語が必要か
- 読み上げと字幕の同期精度は秒かフレームか
- フォントの配布・商用利用条件を確認できるか

## 5. プレビューと書き出し

- プレビューと最終書き出しで一致させる範囲は何か
- 出力形式、解像度、fps、映像・音声コーデック、品質は何か
- ハードウェア支援が必要か。CPUだけでも動く必要があるか
- 中断、再開、進捗、失敗理由をどう表示するか
- 出力先、ファイル名、上書き、容量不足をどう扱うか

## 6. 素材管理

- 素材はローカル、クラウド、外部ライブラリのどこに置くか
- 素材ID、元ファイル名、参照元、ライセンスを記録するか
- ファイル移動・改名後も過去作品を再生成できるか
- 欠けた素材を検出・復旧できるか
- 大容量素材をGitへ入れない仕組みがあるか

## 7. 利用環境

- Windows、macOS、Linux、ブラウザ、スマートフォンのどれで操作するか
- 編集処理は利用端末、サーバー、クラウドのどこで行うか
- スマートフォン操作時も、出力動画の比率を独立して維持するか
- オフライン、低速回線、外出先で使うか
- 同時に複数の書き出しを行うか

## 8. 確認用サンプル

最初に、権利上安全な短いサンプルを1つ決めます。

- 入力素材
- 操作・台本
- 期待する長さとフレーム数
- 期待する映像の静止画
- 期待する音量・音声
- 出力ファイルの情報

新機能は、このサンプルを壊さない回帰テストを追加してから採用します。

## 9. 実装前にAIが提案するもの

- 最終的な利用の流れ
- v1.0.0へ必要な最小の**実用範囲**
- 技術的に危険な点を確かめるAlpha
- 自動確認できるものと、人の目・耳・実端末が必要なもの
- 外部ツール、コーデック、素材、サービスのライセンスと費用

AIは「実装しやすい機能」だけを選んで目標と呼びません。
