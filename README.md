# sudebnik-dev

AIと協業して開発を進めるための、文書の骨格と運用ルールのテンプレート。

## これは何か

AIアシスタントと一緒に開発を進めるときに効く、5つの文書とルールの雛形です。次の3つの問題への実戦的な答えが入っています：

- **AIは予告なく止まる**（使用量の上限等）。止まった瞬間には何も書けない
- **文書は放っておくと腐る**。古い情報が残っていると誤動作のもとになる
- **同じ事実を2か所に書くと、写した瞬間から片方が嘘になる**

## 使い方

1. このリポジトリをテンプレートとしてコピーする
2. `AGENTS.md` の役割欄を自分のプロジェクトに合わせて書き換える
3. `HANDOFF.md` の【 】を埋める
4. `STATUS.md` の「現在地」を書き始める

## 読む順

1. **初めてこのrepoに入るなら** → [HANDOFF.md](./HANDOFF.md)
2. **いまどうなっているか** → [STATUS.md](./STATUS.md)
3. **作業するなら** → [AGENTS.md](./AGENTS.md)（役割・標準ループ・記録の規則）
4. **作る順序** → [ROADMAP.md](./ROADMAP.md)
5. **作業履歴** → [WORKLOG.md](./WORKLOG.md)

## 背景の考え方

- 正本はrepoに置く。チャットの会話に残さない
- 薄く保つ。戻しやすい粒度で進める
- 迷ったら止めて報告する
- 判断は人間、実装はAI。AIに「完成」「正式版」を宣言させない
